## 📖 Executive Summary

The **Data Science Workbench** repository is a hands-on laboratory portfolio developed at **Alliance University** focused on data wrangling, missing data imputation, outlier detection, and statistical distribution modeling. Across structured Jupyter notebooks, the project demonstrates empirical feature transformation pipelines, bivariate correlation analysis, and early predictive estimation.

---

## 🔬 Laboratory Curriculum & Assignments

| Notebook | Focus Area | Analytical Methodology |
| :--- | :--- | :--- |
| `_Assignment1.ipynb` | Data Cleaning & Outlier Scrubbing | Quantile filtering, IQR boundary calculation, missing value handling |
| `Assignment-2(Data Science).ipynb` | Bivariate Analysis & Predictive EDA | Correlation heatmaps, feature normalization, distribution shape skewness |

---

## ✨ Key Data Science Techniques Implemented

- **🧹 Data Cleansing Pipelines:** Identifying and remediating missing, corrupt, and duplicated observations.
- **📊 Statistical Outlier Identification:** Utilizing Interquartile Range (IQR) and Z-score metrics to filter anomalies.
- **📈 Exploratory Visualizations:** Histogram distributions, Kernel Density Estimation (KDE), pairplots, and correlation matrices.

## ⚙️ Reproducible Quickstart & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/keerthi19hub/Data-Science.git
cd Data-Science
```

### 2. Setup Virtual Environment & Dependencies
```bash
python -m venv venv
venv\Scripts\activate  # Linux/macOS: source venv/bin/activate

pip install pandas numpy seaborn matplotlib jupyter
```

### 3. Launch Notebooks
```bash
jupyter notebook
```
